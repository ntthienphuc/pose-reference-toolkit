# Contributing

Discuss behavior changes in an issue with a minimal, non-private pose example and expected result. Install `.[server,dev]`, run `python -m unittest discover -s tests -v`, and reproduce the synthetic CLI workflow. Changes to normalization, quality gates, tolerance, alignment or score semantics require a versioned contract and a regression case demonstrating why.

Do not submit participant video, credentials or third-party material without documented redistribution rights. Attribute imported code and preserve compatible upstream notices. Synthetic motion must stay labelled as synthetic. New recognition, learner assessment or performance claims need an explicit dataset/partition/policy/runtime receipt.
